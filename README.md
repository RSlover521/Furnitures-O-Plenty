## 🌟 Furnitures O’ Plenty

Furnitures O’ Plenty (FOP) expands your decorating possibilities by bringing together the best of **Biomes O’ Plenty** and **MrCrayfish’s Furniture Mod: Refurbished**. Enjoy furniture crafted from every unique Biomes O’ Plenty wood type—from maple to empyreal—all designed to blend seamlessly with Minecraft’s style.

**FOP supports both Forge and Fabric on Minecraft 1.20.1.**

Decorate your world, match your biomes, and make your builds truly feel like home!

## 📦 Overview

FOP combines the wood types from Biomes O’ Plenty with furniture from MrCrayfish’s Furniture Mod: Refurbished. Forge and Fabric builds share the same registry IDs, resources, recipes, and world-compatible content.

### Supported platforms

| Minecraft | Mod loader | Loader version                 |
|-----------|------------|--------------------------------|
| 1.20.1    | Forge      | Forge FML 47.4.x or newer      |
| 1.20.1    | Fabric     | Fabric Loader 0.16.10 or newer |

---

## 🪑 Features

Furniture variants for all supported Biomes O’ Plenty wood types:

- Crates and storage jars
- Chairs, tables, and desks
- Ceiling fans and mailboxes
- Baths, toilets, and basins
- Storage cabinets and drawers
- Lattice fences and lattice fence gates
- Kitchen cabinetry, kitchen drawers, and kitchen sinks
- Cutting boards, kitchen cabinets, and kitchen storage cabinets
- Backpack shelves when MrCrayfish’s Backpacked is installed

**Wood types:** Fir, Pine, Maple, Redwood, Mahogany, Jacaranda, Palm, Willow, Dead, Magic, Umbran, Hellbark, and Empyreal.

**Hedge leaf types:** Flowering Oak, Cypress, Snowblossom, Origin, Rainbow Birch, Fir, Pine, Red Maple, Orange Maple, Yellow Maple, Redwood, Mahogany, Jacaranda, Palm, Willow, Dead, Magic, Umbran, Hellbark, and Empyreal.

Backpacked shelf compatibility is available on both Forge and Fabric. Use the Backpacked build made for your selected loader.

## 💾 Installation

1. Install **Minecraft 1.20.1**.
2. Install either **Forge 47+** or **Fabric Loader 0.16.10+**. Do not install both loaders in the same Minecraft instance.
3. Download the FOP JAR marked for your loader from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/furnitures-o-plenty), [Modrinth](https://modrinth.com/mod/furnitures-o-plenty), or [GitHub Releases](https://github.com/RSlover521/Furnitures-O-Plenty/releases).
4. Install the required dependencies listed below, selecting the same Minecraft version and loader as FOP.
5. Place FOP and its dependencies in your instance’s `mods` folder, then launch Minecraft.

### Required dependencies

| Dependency                                                                                                    | Minecraft version          | Notes                                                                           |
|---------------------------------------------------------------------------------------------------------------|----------------------------|---------------------------------------------------------------------------------|
| [Architectury API](https://modrinth.com/mod/architectury-api)                                                 | 1.20.1                     | Required on Forge and Fabric                                                    |
| [Biomes O’ Plenty](https://www.curseforge.com/minecraft/mc-mods/biomes-o-plenty)                              | 1.20.1, version 19.0.0.90+ | Install the matching Forge or Fabric build                                      |
| [MrCrayfish’s Furniture Mod: Refurbished](https://www.curseforge.com/minecraft/mc-mods/refurbished-furniture) | 1.20.1, version 1.0.14+    | Install the matching Forge or Fabric build                                      |

Biomes O’ Plenty and MrCrayfish's Refurbished Furniture may also require loader-specific supporting libraries such as TerraBlender, GlitchCore, and Framework. Follow the dependency list shown by the download platform for the exact BOP file you install.

### Optional Backpacked compatibility

- **Forge:** [Backpacked](https://www.curseforge.com/minecraft/mc-mods/backpacked), compatible 1.20.1 Forge release
- **Fabric:** [Backpacked (Fabric)](https://www.curseforge.com/minecraft/mc-mods/backpacked-fabric), version 2.2.8 for Minecraft 1.20.1

Backpacked is optional. Without it, FOP loads normally and does not register the backpack shelf variants.

## 🛠️ Building from source

FOP uses an Architectury multi-loader structure with `common`, `forge`, and `fabric` modules. Java 17 is required.

```shell
./gradlew build
```

Loader-specific development clients:

```shell
./gradlew :forge:runClient
./gradlew :fabric:runClient
```

Built loader JARs are written to:

- `forge/build/libs/`
- `fabric/build/libs/`
